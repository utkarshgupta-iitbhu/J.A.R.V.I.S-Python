# ⚡ J.A.R.V.I.S Desktop Assistant

> **J.A.R.V.I.S — Just A Rather Very Intelligent System**
> A desktop assistant built with **Python** and **CustomTkinter** featuring voice interaction, productivity tools, web utilities, and a sleek cyber-themed interface.

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/jarvis-desktop-assistant.git
cd jarvis-desktop-assistant
```

---

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 3️⃣ Run the Application

```bash
python jarvis.py
```

---

## 📦 Requirements

* Python 3.9+
* Internet connection (for APIs/features like weather/news/wiki)

### Main Libraries Used

* CustomTkinter
* pyttsx3
* requests
* wikipedia
* simpleeval

## 🧪 Supported Commands

### 🧠 Productivity

| Command           | Action        |
| ----------------- | ------------- |
| `todo add <task>` | Add a task    |
| `todo list`       | View tasks    |
| `todo done <num>` | Complete task |
| `remember <note>` | Save note     |
| `show notes`      | Display notes |
